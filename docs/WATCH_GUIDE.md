# 手表应用使用说明

当前配套：Android 活力记录 **0.12.3**、GT2 / BlueOS 3 活力记录 **0.5.3**、OrbitV“活力记录同步”扩展程序 **1.2.0**。

覆盖更新三个安装包，原记录和首次配对信息继续使用。手机包为 APK；手表 RPK 和扩展程序 ovpkg 使用 OrbitV 安装。不要卸载后重新安装。

1. 手机“我的 → 通过 OrbitV 同步手表”开启持续连接。首次使用复制配对信息，在扩展程序粘贴保存。
2. 在 OrbitV 连接 GT2，保持“活力记录同步”扩展程序和手表活力记录页面打开。
3. 手机点击“更新到手表”，或手表点击“获取更新”。只有这两种主动操作才传输记录；保存饮食、运动或 AI 建议不会同步到手表。
4. 等待手表显示“确认已回传”。手机也会显示已确认完成。只更新新增或内容变化的日期，保留其他历史缓存。
5. 手表用日期两侧箭头切换前后一天；点击日期选择已有缓存日期。切换日期只读本地缓存，无需蓝牙。
6. 点击“三餐”进入早、午、晚餐卡片，再点某餐查看具体食物；加餐保留在晚餐详情的入口。

“获取更新”、连接状态和版本信息仅在手表主页面最底部显示；二级页面只展示当前内容与返回入口。

能量卡片同时显示当天消耗参考和登记摄入，差值就是消耗参考减登记摄入。正值绿色、负值红色；没有登记食物时登记摄入为 0。不从差值中再扣目标或调整量。消耗估算公式沿用手机现有算法。

手机首页点击每日步数卡片，或其下方“录入／修改每日步数”按钮即可设置所选日期的步数。手表为手机数据的只读看板。

详细安装、数据路径、构建与验证范围见 [ORBITV_SYNC.md](ORBITV_SYNC.md)。旧 BLE 连接入口已移除，历史研究保存在 [WATCH_BLE_HISTORY.md](WATCH_BLE_HISTORY.md)，不属于当前运行路径。

0.5.3 已恢复 0.5.0 的全屏滚动及卡片尺寸，仅把文字居中；没有缩小整个界面。BMI 与体脂率卡片新增同手机范围的数轴和当前值箭头。需要手机更新后手动同步一次，旧缓存中的没有数轴的日期不会凭空套用范围。本次必须同步更新扩展程序至 1.2.0。

持续连接保存开关与配对信息，不再每 15 分钟关闭；断线后页面自动重新检测。手机与扩展程序显示三段状态：手机 App、手表蓝牙通道、手表活力记录。等待均就绪后手动更新即可。关闭 OrbitV 扩展页会停止其服务，这是 OrbitV 的生命周期限制；重新打开后自动检测，不会因重连自行更新健康记录。

手表旧缓存缺少数轴时会写明“参考数轴尚未同步”；请更新配套软件并完成一次获取更新。资料不适用时显示原因。当前数轴的 GT2 视觉显示还需本版实机确认。
