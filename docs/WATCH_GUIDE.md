# 手表应用使用说明

当前开发配套：Android 活力记录 **0.14.0**、GT2 / BlueOS 3 活力记录 **0.7.0**。本版直接通过原生 BLE 通信，不需要 OrbitV 扩展程序和手动配对码。两端已编译通过，手表协议测试 40 项、手机 JVM 测试 49 项通过，完整真机同步与长期后台表现待验证。首次连接与实现细节见 [手表直连实现](LINK_IMPLEMENTATION.md)，协议见 [活力直连协议 v1](LINK_PROTOCOL.md)。

之后使用时覆盖更新两个安装包，保留正式应用与记录。手机 APK 可直接安装，手表 RPK 可继续用 OrbitV 安装；同步运行不需要打开 OrbitV。

1. 打开手表“活力记录”，保持页面可见，确认主页底部显示“直连服务已开启”。
2. 手机“我的 → 手表直连”允许附近设备权限，点击“搜索手表”，选择 GT2。
3. 连接信息由手机自动生成并在两端保存，之后重连无需输入；手机前台服务维护持续连接，手表端广播看门狗负责让手机随时能重新连上。切换手机时，先关闭旧手机连接，再在手表“连接管理”清除旧手机连接，健康记录保留。
4. 手机点击“更新到手表”，或手表主页点击“获取更新”。两端保存确认后才显示完成。已有请求在断线、应用重启或手表重启后都能继续，不因重连创建新请求。
5. 需要确认链路是否正常时，可在手机点击“连接自检”，它会向手表发送一次加密往返并回显结果；自检不传输任何健康记录。
6. 手表日期箭头切换前后一天；点击日期选择缓存日期，离线也可查看。
7. 点“三餐”进入早餐、午餐、晚餐卡片，再进入某餐查看食物。二级页面保留内容和返回入口；更新按钮只在主页最底部。

能量卡片的红绿差值只等于当天消耗参考减当天登记摄入；正值绿色，负值红色。体重/BMI 与体脂率数轴沿用手机提供的范围，不自行从 BMI 推算体脂率。手机每日步数仍由用户按天录入。

手机健康记录、AI 配置与手表日期缓存保留。旧缓存缺少数轴时，应在完成配对后主动更新；资料不适用时显示原因。系统回收或挂起手表应用时连接可能中断，长期熄屏表现尚待本版实机验证。蓝牙连接恢复不触发新的健康记录同步。

旧扩展方案的历史说明保留在 [ORBITV_SYNC.md](ORBITV_SYNC.md)。旧通信探针 `com.lrh.healthvivo.watch.directprobe` 使用另一个服务 UUID，与本版互不干扰，也可以直接卸载。升级到本版后需要一次首次连接（手机搜索并选择手表，无需输入代码），因为旧协议的凭据不会被当成新协议的凭据；手表按天缓存原样保留，历史日期不需要重新同步。
