标题：申请 vivo Health Kit Android 本地只读接口资料与测试权限

正文：

你好，我正在开发 Android 应用“活力记录”，包名 com.lrh.healthvivo。测试设备为 vivo X80，OriginOS 6 / Android 16；vivo 健康版本为 7.1.1.02。应用用于分析 vivo 健康中已有的饮食、运动与体重记录，不自行采集传感器数据，不向 vivo 健康写入数据，首版在手机本地保存与计算。

已拥有 vivo 开发者账号，之前申请的是智能终端 SDK 密钥。现根据《vivo健康服务平台简介》中所述的本地 API 能力，申请 Health Kit Android 本地接入文档、SDK / 示例、读取权限和测试指引。请确认以下问题：

1. 个人开发者自用应用是否可以申请本地只读测试权限？是否需要额外资质、合同或上架？
2. 请提供本地 SDK 的正式下载入口、支持版本、初始化与用户授权方法、应用包名和签名配置要求。
3. 能否读取每日合并步数、运动记录（含运动类型、时长、距离、消耗千卡、异常标识、记录 ID）？历史范围、分页、修改/删除记录与撤销授权如何处理？
4. OriginOS 6 的 vivo 健康“健康减脂”中用户上传的食物是否对第三方开放？具体是否包含食物名称、食用时间、份量、热量、营养素、照片、减脂点数与用户修订值？请明确可读取字段与权限名。
5. 能否读取体重、身高、体脂和用户档案，以及每日活动消耗、基础代谢或全天总消耗？请明确单位、统计范围、数据来源及合并规则。
6. “健康减脂”点数是否有公开的热量换算规则？没有官方规则时，本应用不会把点数作为千卡计算。
7. 本地 API 是否依赖云同步或联网？是否支持离线读取？延时、去重、多设备合并、时区与跨午夜运动的归属规则是什么？

本应用希望只读取用户明确授权的数据。若饮食或体重字段尚不开放，也请明确说明，并提供可供用户自主使用的正式导出方式及文件格式（若有）。谢谢。

注意：Health Kit App ID 待独立创建；不要把此前智能终端 SDK 的密钥当成 Health Kit 密钥填写。提单可附上 artifacts/phone-signature.txt 中的应用签名指纹，不必提交私钥或账号密码。
